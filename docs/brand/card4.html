04The seal

A decision, first.

SCPE ships as a GitHub Action, live on the Marketplace. It posts a decision-first seal on a pull request: identity, key source, risk band, tests, provenance.

Real output, not a mock-up: the verifier's verdict on a signed contribution, checked against the key github.com publishes for that account.
require: trueFAILING CHECK
With require: true, an unattested pull request becomes a failing check instead of a comment.
The seal is a report, never an approval. It says who signed and that nothing moved. Whether the code is any good stays a human call.
